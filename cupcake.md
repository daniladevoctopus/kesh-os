# Cupcake

Визуальный стиль SneakDeak. Версия 1.0, сентябрь 2026.
Референсная реализация — сайт kesh.sneakdeak.net.

---

## 1. Что это за стиль

Cupcake — тёплый матовый стиль для продуктов, у которых внутри много техники, а снаружи должно быть спокойно. Белая база, один оранжевый акцент, поверхности из матового стекла и элементы, которые хочется нажать: у каждого есть верхняя подсветка, край и отклик на нажатие.

Три правила, из которых выводится всё остальное:

1. **Один акцент на экран.** Оранжевый обозначает действие и текущее положение. Всё, что не действие и не «вы здесь», остаётся серым.
2. **Материал, а не декорация.** Глубина создаётся светом на краю и мягкой тенью, а не градиентными заливками и цветными свечениями.
3. **Данные показываются как данные.** Таблица — таблицей, спецификация — парой «параметр / значение». Технический контент не режется на одинаковые карточки.

Название: слои стиля собираются как капкейк — плотная основа (поверхность), матовая глазурь (стекло), одна ягода сверху (акцент). Больше одной ягоды не кладут.

## 2. Цвет

### Светлая схема — основная

| Роль | Токен | Значение | Где применяется |
|---|---|---|---|
| Фон страницы | `--cc-bg` | `#FFFFFF` | подложка, фон кнопок по умолчанию |
| Поверхность 1 | `--cc-surface-1` | `#F7F5F3` | карточки, таблицы, поля ввода |
| Поверхность 2 | `--cc-surface-2` | `#EFEDEA` | шапки таблиц, чипы |
| Линия | `--cc-line` | `#E2DED9` | все границы и разделители |
| Текст | `--cc-text` | `#121110` | основной текст и заголовки |
| Текст вторичный | `--cc-muted` | `#6B6660` | подписи, описания, неактивное меню |
| Текст третичный | `--cc-faint` | `#8A847C` | юридический мелкий шрифт, плейсхолдеры |
| Акцент | `--cc-accent` | `#D97757` | заливка главной кнопки, индикаторы |
| Акцент насыщенный | `--cc-accent-deep` | `#B85C3E` | акцентный текст, границы, фокус |
| Акцент фоновый | `--cc-accent-tint` | `#FBEDE7` | подложка бейджа выпуска |
| Текст на акценте | `--cc-on-accent` | `#FFFFFF` | подпись главной кнопки |

### Тёмная схема

Включается атрибутом `data-theme="dark"` на `<html>`. Меняются только значения токенов, разметка и классы те же.

| Токен | Значение |
|---|---|
| `--cc-bg` | `#000000` |
| `--cc-surface-1` | `#141312` |
| `--cc-surface-2` | `#1E1C1A` |
| `--cc-line` | `#2E2B27` |
| `--cc-text` | `#F2F0ED` |
| `--cc-muted` | `#938F88` |
| `--cc-accent-deep` | `#E28460` (светлее акцента, а не темнее) |
| `--cc-accent-tint` | `rgba(217,119,87,.11)` |
| `--cc-on-accent` | `#1A0E08` |

На тёмном акцентный текст берётся **светлее** базового оранжевого, на светлом — темнее. Это единственная роль, которая инвертируется.

### Границы применения акцента

Оранжевым красятся: главная кнопка, активный пункт меню и его подчёркивание, числа в полосе показателей, заголовки карточек, номера статей, состояние фокуса, точка-индикатор. Всё остальное — серая шкала.

Оранжевым **не** красятся: большие плашки и целые секции, текст абзацев, иконки «просто так», ссылки внутри текста, границы карточек в обычном состоянии.

### Цвета сервисов

Discord `#5865F2` и GitHub `#1C1B1A` сохраняют свою окраску — это опознавательный знак, а не украшение. Других цветных кнопок в стиле нет.

## 3. Типографика

| Роль | Гарнитура | Начертания | Где |
|---|---|---|---|
| Дисплейная | Unbounded | 500, 700 | h1, крупные числа |
| Текстовая | Golos Text | 400, 500, 600, 700 | всё остальное |
| Моноширинная | JetBrains Mono | 400, 500 | имена файлов, номера KB, URL, значения параметров |

Все три с кириллицей. Unbounded используется точечно: один заголовок первого уровня на страницу и числа в полосе показателей. Если поставить её на h2 и h3, страница станет шумной.

**Шкала**

| Уровень | Размер | Межстрочный | Трекинг |
|---|---|---|---|
| h1 | `clamp(2.4rem, 6.2vw, 4.1rem)` | 1.12 | −0.04em |
| h2 | `clamp(1.65rem, 3.4vw, 2.4rem)` | 1.12 | −0.03em |
| h3 | 1.06rem | 1.3 | −0.015em |
| Лид | 1.06rem | 1.6 | −0.005em |
| Текст | 1rem | 1.65 | −0.005em |
| Вторичный | 0.94rem | 1.6 | — |
| Подпись | 0.86rem | 1.45 | — |
| Мелкий | 0.80rem | 1.6 | — |

Отрицательный трекинг обязателен на заголовках: обе гарнитуры при крупных кеглях расходятся.

**Длина строки** — до 72 знаков для абзацев, до 52 для лида под заголовком. Ограничение задано в `max-width` через `ch`, не в пикселях.

**Регистр** — предложениями. Заголовки без точки. Капслока в стиле нет нигде: ни в надзаголовках, ни в подписях, ни на кнопках.

## 4. Сетка и ритм

- Контейнер `--cc-wrap` = 1120px, боковые поля `--cc-gutter` = 22px.
- Шаг сетки 4px. Разрешённые отступы: 4, 8, 12, 16, 22, 32, 48, 74.
- Вертикальный ритм секции: 74px сверху и снизу, на узких экранах 48px.
- Заголовок секции и её текст — до 60 знаков, отступ до содержимого 34px.
- Контрольные точки: 900px (двухколоночные блоки схлопываются, показатели 4 → 2) и 560px (всё в одну колонку).

**Выравнивание** — по левому краю везде, включая заголовки секций и полосу показателей. Центрирование в Cupcake не используется: оно ломает вертикальную линию, по которой читается страница.

## 5. Форма и материал

| Радиус | Токен | Для чего |
|---|---|---|
| 6px | `--cc-r-xs` | контур фокуса |
| 10px | `--cc-r-s` | кнопки, поля ввода |
| 16px | `--cc-r-m` | карточки, панели, таблицы, изображения |
| 24px | `--cc-r-l` | плита под скриншот |
| 999px | `--cc-r-pill` | чипы и бейджи |

Радиус кодирует размер элемента: чем крупнее блок, тем больше скругление. Один радиус на всё — самый быстрый способ сделать страницу шаблонной.

**Три уровня глубины**, больше не вводить:

1. **Плоский** — фон страницы и блоки, сидящие прямо на нём.
2. **Поверхность** — заливка `--cc-surface-1` и рамка `--cc-line`. Тени нет. Это карточки и таблицы.
3. **Стекло** — `--cc-glass` + `backdrop-filter: blur(14px)` + внутренняя подсветка сверху + тень `--cc-shadow-2`. Это панели и шапка.

**Формула тактильности.** Любой элемент, который можно нажать, получает три вещи: светлую линию по верхней внутренней кромке (`inset 0 1px 0`), заметный край, сдвиг на 1px вниз при нажатии. Без первого элемент выглядит плоской заливкой, без третьего — картинкой.

**Свечение фона** — один `radial-gradient` оранжевого в правом верхнем углу, 16% непрозрачности, плюс слабый отголосок слева. Ставится один раз на страницу, фиксированным слоем под контентом. Второе свечение в середине страницы стиль не допускает.

## 6. Компоненты

### Кнопка

Три вида, различаются ролью, а не размером:

- **Главная** (`.cc-btn--primary`) — оранжевый градиент сверху вниз, белая подпись. Одна на экран. Всегда описывает результат: «Скачать образ», а не «Подробнее».
- **Обычная** (`.cc-btn`) — белая, с рамкой. Для всего остального.
- **Сервисная** (`--discord`, `--github`) — в цвете сервиса.

Высота 44px, на компактных местах 38px (`--small`). Иконка перед текстом, промежуток 9px. Стрелки «→» в подписи кнопки стиль не использует.

### Панель из стекла

`.cc-panel` — для блоков, которые должны выделяться из потока: центр загрузки, блок сообщества, поддержка. Панель всегда лежит на пустом фоне страницы, никогда внутри карточки. Вкладывать стекло в стекло нельзя: блюр складывается и края грязнятся.

### Карточка

`.cc-card` — плоская поверхность с рамкой, отступ 22px, заголовок акцентным цветом, текст вторичным. Карточки применяются только к однородным наборам: возможности системы, юридические положения. Если элементы набора разной природы, карточки не ставятся.

### Плита

`.cc-slab` — оправа под скриншот: 9px поля, диагональный градиент от белого к серому, подсветка по верхней кромке, крупная мягкая тень. Даёт изображению физический корпус. Одна на экран, в герое.

### Полоса показателей

`.cc-facts` — 2–4 значения в общей рамке, разделённые линиями в 1px. Числа дисплейной гарнитурой, акцентным цветом; подпись под числом вторичным. Каждое значение должно быть проверяемым: «128 МБ», «5–15 с». Оценочные формулировки вроде «молниеносно» в эту полосу не ставятся.

### Таблица

Заголовок строки — `<th>` в 30% ширины, значение — `<td>`. Шапка на `--cc-surface-2`, вторичным цветом, 0.85rem, без жирного. Разделители только горизонтальные, у последней строки границы нет. Таблица заворачивается в `.cc-table-wrap` со скруглением и обрезкой.

### Чип

Метаданные: размер файла, архитектура, дата сборки. Серый по умолчанию, `--accent` для статуса выпуска. Внутри акцентного чипа может стоять точка-индикатор.

### Поле ввода

Заливка `--cc-surface-1`, рамка `--cc-line`, при фокусе рамка становится оранжевой. Плейсхолдер показывает пример запроса, а не повторяет название поля: «Например: USB, BSOD, KB082001».

### Шапка

Две строки. Верхняя: бренд слева, справа сервисные кнопки и поиск. Нижняя: горизонтальный ряд разделов, активный подчёркнут оранжевым. Вся шапка липкая, фон полупрозрачный с блюром 18px. На узких экранах ряд разделов прокручивается горизонтально — гамбургер стиль не использует.

### Аккордеон

Для справочных статей: `<details>` со строкой «номер — заголовок — дата». Раскрытая часть на белом фоне, поля описаны списком определений `<dl>`: подпись вторичная 0.8rem, значение основное 0.94rem.

## 7. Движение

Один поставленный эпизод на страницу: появление героя тремя ступенями по 80мс, 700мс, кривая `cubic-bezier(.22,.9,.3,1)`. Всё остальное движение — только ответ на действие: нажатие кнопки, раскрытие статьи, открытие изображения, подсветка найденного раздела.

Чего в Cupcake нет: появления каждой секции при скролле, параллакса, анимации чисел, всплывания карточек при наведении, бесконечных лент.

`prefers-reduced-motion: reduce` отключает появление и подсветку и переводит прокрутку в мгновенную. Это часть стиля, а не опция.

## 8. Текст в интерфейсе

- Кнопка называет результат: «Скачать образ», «Задать вопрос в Discord», «Копировать».
- Подпись под числом объясняет, что измеряли: «минимум оперативной памяти», а не «памяти».
- Пустое состояние даёт следующий шаг: «По этому запросу статей нет. Задайте вопрос в Discord».
- Ошибка говорит, что произошло и что сделать. Извинения не пишутся.
- Проверяйте обещания против собственных цифр. «Помещается в оперативную память» при образе в 389 МБ и минимуме в 256 МБ — не формулировка, а ошибка.

## 9. Доступность

- Контраст: основной текст к фону 16:1, вторичный 5.4:1, белый на акценте 4.6:1. Ставить `--cc-accent` текстом на белом нельзя — только `--cc-accent-deep`.
- Фокус виден всегда: контур 2px цвета `--cc-accent-deep` с отступом 3px. Снимать `outline` без замены запрещено.
- Цель нажатия от 44×44px.
- Смысл никогда не передаётся одним цветом: активный пункт меню помечен и цветом, и подчёркиванием.
- Модальное окно закрывается по Escape и по клику вне содержимого, фокус возвращается на открывший элемент.

## 10. Перенос на другие платформы

Имена токенов одинаковы во всех реализациях, меняется только синтаксис.

**JSON**

```json
{
  "color": {
    "bg": "#FFFFFF",
    "surface-1": "#F7F5F3",
    "line": "#E2DED9",
    "text": "#121110",
    "muted": "#6B6660",
    "accent": "#D97757",
    "accent-deep": "#B85C3E",
    "on-accent": "#FFFFFF"
  },
  "radius": { "s": 10, "m": 16, "l": 24 },
  "space": [4, 8, 12, 16, 22, 32, 48, 74]
}
```

**Compose**

```kotlin
object Cupcake {
    val Bg = Color(0xFFFFFFFF)
    val Surface1 = Color(0xFFF7F5F3)
    val Line = Color(0xFFE2DED9)
    val Text = Color(0xFF121110)
    val Muted = Color(0xFF6B6660)
    val Accent = Color(0xFFD97757)
    val AccentDeep = Color(0xFFB85C3E)

    val RadiusS = 10.dp
    val RadiusM = 16.dp
    val RadiusL = 24.dp
}
```

Стекло без `backdrop-filter` подменяется полупрозрачной заливкой поверхности плюс `elevation`. Верхняя подсветка на нативных платформах делается градиентной рамкой в 1px от белого 90% к прозрачному.

## 11. Чек-лист перед сдачей

- [ ] На экране ровно одна главная кнопка.
- [ ] Оранжевый встречается только в разрешённых ролях из раздела 2.
- [ ] Unbounded стоит на одном заголовке и на числах, больше нигде.
- [ ] Радиусы различаются по размеру блока.
- [ ] Стекло не вложено в стекло.
- [ ] Все отступы кратны 4.
- [ ] Абзацы не шире 72 знаков.
- [ ] Ни одного слова капслоком.
- [ ] Появление при скролле не навешано на секции.
- [ ] Фокус виден на каждом интерактивном элементе.
- [ ] Тёмная схема проверена переключением `data-theme`.
- [ ] Числа на странице сверены с таблицей требований.
