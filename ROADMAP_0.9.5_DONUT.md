## 2. Графическая подсистема и мониторы
- [ ] **Автоопределение родного разрешения (EDID / DDC):**
  - [ ] Считывание физического разрешения экрана ноутбука/монитора через VBE DDC / EDID.
  - [ ] Автоматический выбор родного широкоформатного режима (16:9 / 1366x768 или 1920x1080) вместо сжатого 800x600/1024x768.
- [ ] **Базовый видеоадаптер KeshOS:**
  - [ ] Поддержка чистого вывода через UEFI GOP Linear Framebuffer для современных ноутбуков.
  - [ ] Сохранение стабильной плавной работы программного курсора без конфликтов с окнами.

---

## 3. Управление питанием ACPI (Power Management)
- [ ] **Корректное завершение работы:**
  - [ ] Выключение питания ноутбука/ПК по кнопке «Завершение работы» в меню «Пуск» без зависания на заставке.
  - [ ] Корректная мягкая перезагрузка системы.
- [ ] **Индикатор батареи:**
  - [ ] Отображение уровня заряда аккумулятора ноутбука в системном трее (`battman.dll`).

---

## 4. Звук и мультимедиа
- [ ] **High Definition Audio (HDA):**
  - [ ] Интеграция универсального аудиодрайвера для современных чипов Realtek ALC и Intel HD Audio.
  - [ ] Рабочий ползунок громкости в системном трее (`sndvol32.exe`).
- [ ] **Звуковая схема Donut:**
  - [ ] Новый фирменный мягкий звук запуска системы (`Donut_Startup.wav`).
