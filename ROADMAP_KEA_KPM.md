# 🚀 KeshOS Roadmap: Экосистема .KEA, Ksh64, KshWin32 и KPM

Данный документ фиксирует архитектурный стек приложений и пошаговый план развития экосистемы KeshOS.

---

## 🏗 Архитектурные основы KeshOS

### 1. Формат приложений: `.kea` (Kesh Executable Application)
* **Контейнер**: Расширенный стандарт ELF64 с фирменным заголовком метаданных KeshOS (`.kea_hdr` / `.note.kesh`).
* **Структура пакета**:
  * Сигнатура: `KEA\1` (`0x0141454B`).
  * Метаданные: Имя приложения, версия, автор, категория, запрашиваемые права.
  * Встроенная векторная/растровая иконка (RGBA 32x32 / 48x48) для меню и дока.
  * 64-битные сегменты кода и данных (`.text`, `.rodata`, `.data`, `.bss`).
* **Изоляция и пути**: Установка в Unix VFS по стандарту `/apps/<appname>/`.

---

## 🎯 3 Вариации приложений в KeshOS

1. **Эксклюзивный нативный софт (`ksh64`)**:
   * Разработка на **C++20**.
   * Прямая динамическая/статическая линковка с системными библиотеками `/system/lib/` (`libksh64`).
   * Мгновенный запуск, ультра-низкий вес (20–50 КБ).
   * Прямой доступ к жидкому стеклу (`ksh_set_glass_effect`), аппаратному ускорению, окнам со светофорами и системному IPC.

2. **Портированный Unix/POSIX софт (`elf64`)**:
   * Стандартные ELF64 бинарники.
   * Работают через базовые POSIX-совместимые системные вызовы ядра (VFS, fork/spawn, pipes, exit, memory mapping).

3. **Порт Windows-софта (`kshwin32`) и нативный запуск `.exe`**:
   * **Исходный порт C++**: заголовок `<kesh/win32.h>`, транслирующий Win32 API (`CreateWindow`, `BeginPaint`, `DefWindowProc`, GDI) напрямую в вызовы `ksh64` без оверхеда.
   * **Немодифицированный `.exe`**: модульный PE-лоадер и библиотеки совместимости (Wine / ReactOS из `archive/`), подключаемые через команду `kpm install exe`.

---

## 📦 Пакетный менеджер `kpm` (Kesh Package Manager)

* **Установка нативного софта**:
  * `kpm install <app.kea>` — распаковка/проверка сигнатуры в `/apps/`, регистрация в VFS, отправка IPC-сигнала рабочему столу (KeshShell) для мгновенного появления иконки в Доке и Меню Пуск.
  * `kpm list` — список установленных приложений.
  * `kpm remove <app>` — удаление пакета и очистка ярлыков.
* **Модульный рантайм для Windows**:
  * `kpm install exe` — скачивание/развертывание модульного PE-загрузчика и библиотек совместимости из архива (`archive/reactos/wine-upstream`).
  * Позволяет запускать чистые `.exe` файлы прямо из Проводника или Терминала.
